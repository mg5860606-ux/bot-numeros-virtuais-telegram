# 🦅 CORVO BOT - NÚMEROS VIRTUAIS PREMIUM

Bot de Telegram profissional para venda de números virtuais com integração automática **HeroSMS** e pagamentos via **Mercado Pago (PIX)**.

## 🚀 Funcionalidades
- **💎 Interface Premium:** Menus organizados com cabeçalho azul e visual de aplicativo.
- **🌍 Multi-Países:** Suporte a números do Brasil 🇧🇷, EUA 🇺🇸, Indonésia 🇮🇩, Rússia 🇷🇺 e mais.
- **📈 Estoque em Tempo Real:** Exibição de estoque e preços atualizados direto da API.
- **💰 Sistema de Afiliados:** Link de convite com 10% de bônus automático para quem convida.
- **💳 Pagamento PIX:** Integração nativa com Mercado Pago para liberação instantânea de saldo.
- **👑 Painel Admin:** Comando `/painel` exclusivo para o dono do bot gerenciar usuários e saldo.
- **📢 Broadcast:** Envio de avisos globais para todos os usuários do bot.

## 🛠️ Configuração Técnica
O bot foi desenvolvido para rodar em servidores como **HostCoins**, **Render** ou qualquer **VPS**.
- **Porta Dinâmica:** Detecta automaticamente a porta do servidor.
- **Sem Banco de Dados:** Funciona totalmente em memória (Ephemeral).

## 📦 Como Instalar
1. Suba os arquivos para sua hospedagem.
2. Certifique-se de ter o Python 3.10+ instalado.
3. O servidor instalará as dependências via `requirements.txt`.
4. Configure suas chaves no topo do `main.py`:
   - `TOKEN` (Telegram)
   - `SMS_ACTIVATE_API` (HeroSMS)
   - `MERCADOPAGO_ACCESS_TOKEN` (PIX)
